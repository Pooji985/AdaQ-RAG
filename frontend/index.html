2. Moderate question

What is the difference between macro, micro, and weighted averaging when computing multiclass precision and recall?

▾
Detected Intent COMPARISON
Detected Complexity MEDIUM
Selected Strategy HYBRID + Rerank
Pilot Latency 21.5s (2 calls)

Routing Rationale

Entity comparison requires a broader hybrid candidate pool (top-20) combining BM25 keyword matching and FAISS dense vectors, fused via Reciprocal Rank Fusion and CrossEncoder reranking to ensure balanced evidence across all three averaging types.

Saved Grounded Answer

• Macro averaging: Computes metric values for each class independently, then takes the unweighted arithmetic mean; all classes contribute equally regardless of frequency.
• Weighted averaging: Computes per-class metric values, but weights each class score by its true support (prevalence in ground truth).
• Micro averaging: Aggregates true positives, false positives, and false negatives globally across all classes first, which mathematically equals overall accuracy in standard multiclass classification. [Source 3] [Source 1]

3. Complex question

Compare StandardScaler, RobustScaler, and MinMaxScaler in their sensitivity to outliers and resulting output bounds.

▾
Detected Intent COMPARISON
Detected Complexity COMPLEX
Selected Strategy MULTI_STEP (Orchestrated)
Pilot Latency 63.1s (16 calls)

Routing Rationale

Multi-aspect comparative query contrasting 3 estimators across 2 distinct dimensions (outliers and bounds). Routed to multi-step retrieval: decomposed into targeted sub-queries, retrieved iteratively, and validated with evidence sufficiency assessment.

Saved Grounded Answer

• Sensitivity to outliers:
  – StandardScaler: Highly sensitive; mean and variance are distorted by extreme values [Source 1].
  – RobustScaler: Robust; centers on median and scales by Interquartile Range (IQR) [Source 2].
  – MinMaxScaler: Highly sensitive; extreme values compress typical inliers into a narrow range.
• Output bounds:
  – StandardScaler: Unbounded (mean 0, unit variance).
  – RobustScaler: Unbounded.
  – MinMaxScaler: Strictly bounded to specified range (default [0, 1]).

    The Efficiency-Quality Trade-Off

    No universal winner exists. While Hybrid RAG and Adaptive RAG both achieved a top mean answer quality of 3.93 / 4.0, Hybrid pays the cost of dual retrieval (2 calls) for every query, including simple lookups. Adaptive RAG dynamically conserves compute on simple fact questions (1 call) while selectively scaling to hybrid on comparisons.

    Orchestration Overhead & Complex Inquiries

    Full AdaQ-RAG provides structural query decomposition and iterative sufficiency verification. On multi-aspect comparisons (e.g., rag_comp_11), this enables thorough evidence collection, but requires up to 16 retrieval calls and 63.1 seconds of latency.

    Evaluating the Research Hypothesis

    The project hypothesis is that adaptive retrieval can balance answer quality and computational efficiency by modulating retrieval depth based on question complexity. The 3-question pilot supports this hypothesis by matching Hybrid quality with lower average retrieval calls, but a full 90-question benchmark will be required for statistical significance across edge cases.
